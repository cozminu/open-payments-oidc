# Security policy

Please don't open a public issue for a vulnerability. Report it privately through
[GitHub's vulnerability reporting](https://github.com/cozminu/open-payments-oidc/security/advisories/new)
instead.

Include what you found, how to reproduce it, and what an attacker gets out of it. I'll reply as
soon as I can.

Only the latest release gets fixes.

The gaps listed under [Known limits](README.md#known-limits) (DNS rebinding and redirects for
wallet address lookups, per-replica rate limits, no cap on outbound response size) are already
known. Reports that show a practical exploit of one of them are still welcome.
